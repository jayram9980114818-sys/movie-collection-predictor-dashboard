Bollywood Box Office Prediction Studio

An interactive Machine Learning web application built with Streamlit, Scikit-Learn, and Plotlyto forecast Bollywood movie box office collections, visualize 3D decision surfaces, and dynamically diagnose regression model performance.

Features

Executive Dashboard:High-level metrics showing total revenue, average budgets, top ROI genres, and trajectory plots.

Dataset Statistical Summary: Complete distribution statistics including mean, standard error, skewness, and feature correlations.

3D Mesh & Live Visual Forecast:Interactive 3D surface plot displaying actual historical movies alongside live predictions on a Random Forest decision mesh.

Advanced Model Diagnostics:
Real-time calculation of key metrics: $R^2$, Adjusted $R^2$, RMSE, MAE, MAPE, Standard Error, and Explained Variance.
 
 
Tech Stack

- Frontend / Framework: Streamlit
- Machine Learning:Scikit-Learn (RandomForestRegressor, Pipeline, ColumnTransformer, GridSearchCV)
- Data Processing: Pandas, NumPy
- Visualizations: Plotly Express & Plotly Graph Objects
